# 🛍️ StoreApp 

A simple Flutter application that displays products from an API with a clean and responsive design.

## 🚀 Features

- 🧾 **Product Listing** fetched using the `Dio` package.
- 📱 **Responsive UI** using `GridView` for displaying products.
- 🎨 **Clean and modern interface** built with Flutter and Google Fonts.
